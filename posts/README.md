# Carpeta de posts del blog

Aquí irán los artículos del blog en formato **markdown** (`.md`).

Cada archivo será un post (noticias, menciones en medios, contenido de redes
sociales) que más adelante se convertirá automáticamente en una página HTML
y aparecerá listado en `blog.html`.

Formato previsto para cada post:

```markdown
---
titulo: Título del post
fecha: 2026-07-17
---

Contenido del post en markdown...
```
